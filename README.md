# Cyberpunk Promo

> **Live Demo:** [https://lelyaler.github.io/Cyberpunk-only-html-css-js-/](https://lelyaler.github.io/Cyberpunk-only-html-css-js-/)  
> **WordPress Theme:** [https://github.com/Lelyaler/Cyberpunk-wordpress](https://github.com/Lelyaler/Cyberpunk-wordpress)

Атмосферный промо-лендинг в стилистике Cyberpunk 2077, реализованный по дизайн-макету из Figma. Включает адаптивную вёрстку (Pixel-perfect), динамический слайдер первого экрана на Swiper.js с кинематографичным эффектом смены кадров, модальные окна на нативном HTML5 `<dialog>` и валидацию формы на чистом JavaScript.

Вёрстка проекта также интегрирована в кастомную CMS-тему WordPress с шаблонизацией на PHP.

---

## Реализованный функционал

- **Адаптивная вёрстка**: Корректное отображение на всех разрешениях экрана от 320px до десктопов.
- **Адаптивный слайдер первого экрана**: Слайдер на базе Swiper.js с плавным crossfade-переходом, адаптацией под любые пропорции экрана, поддержкой тач-свайпов, автопрокрутки и клавиатуры.
- **Модальные окна на нативном HTML5 `<dialog>`**: Характеристики монитора HP Pavilion, подтверждение розыгрыша, лицензия и политика конфиденциальности. Изоляция фокуса и закрытие по клавише Escape.
- **Семантический выбор платформ**: Нативная группа радиокнопок `<input type="radio">` со стилизацией через современный CSS-селектор `:has()`.
- **Форма розыгрыша**: Асинхронная отправка данных, валидация полей, предпросмотр размера прикрепляемого файла и локальное сохранение билета в `localStorage`.
- **Анимации и доступность**: Появление контента через `IntersectionObserver API` и учёт предпочтений пользователя (`prefers-reduced-motion`).

---

## Стек технологий

- **HTML5**: семантическая разметка, доступность, нативные `<dialog>`.
- **SCSS / CSS3**: БЭМ-методология, компонентная модульная архитектура, селектор `:has()`, Flexbox / Grid.
- **JavaScript (Vanilla ES6+)**: модульная компонентная структура (ES Modules), DOM Events, Swiper.js.
