# Cyberpunk Promo

> **Live Demo:** [https://lelyaler.github.io/Cyberpunk-only-html-css-js-/](https://lelyaler.github.io/Cyberpunk-only-html-css-js-/)
> **WordPress Theme:** [https://github.com/Lelyaler/Cyberpunk-wordpress](https://github.com/Lelyaler/Cyberpunk-wordpress)

Атмосферный промо-лендинг в стилистике Cyberpunk 2077 с адаптивной вёрсткой, интерактивными слайдерами и визуальными эффектами.

Вёрстка проекта также интегрирована в кастомную CMS-тему WordPress с шаблонизацией на PHP для удобного управления контентом.

## Основные возможности

- Адаптивная вёрстка под мобильные устройства, планшеты и десктопы.
- Интерактивные слайдеры на базе Swiper (переключение игровых платформ и галереи промо-материалов).
- Стилизация с использованием препроцессора SCSS по методологии BEM.
- Интеграция в кастомную тему WordPress с разделением на PHP-шаблоны (`header.php`, `footer.php`, `home.php`, `single.php`, `functions.php`).

## Стек

- HTML5
- SCSS / CSS3
- JavaScript
- Swiper
- WordPress / PHP (кастомная тема)
